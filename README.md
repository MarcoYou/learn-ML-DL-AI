# learn-ML-DL-AI

마르코의 AI 공부노트. ML·DL·AI 무료 공개 교재 목록과 학습 노트.

## 교재 받기

```bash
./scripts/download.sh   # 원 저자 사이트에서 books/ 로 내려받음
```

> PDF는 **커밋하지 않는다** (`.gitignore`). 대부분 저자가 "개인 학습용 무료, 재배포 금지" 조건으로 공개했고 이 저장소는 공개 저장소다. 목록·링크·노트만 올린다.

## 목록

원 게시글(LinkedIn)의 제목과 실제 링크 대상이 다른 항목이 있어 **실제 책 기준**으로 적었다.

| # | 실제 책 | 저자 | 원 게시글 제목 | 출처 |
|---|---|---|---|---|
| 1 | Understanding Machine Learning: From Theory to Algorithms | Shalev-Shwartz, Ben-David | 동일 | [PDF](https://cs.huji.ac.il/~shais/UnderstandingMachineLearning/understanding-machine-learning-theory-algorithms.pdf) |
| 2 | Mathematics for Machine Learning | Deisenroth, Faisal, Ong | Mathematical Foundations of ML | [PDF](https://mml-book.github.io/book/mml-book.pdf) |
| 3 | Mathematical Analysis of Machine Learning Algorithms | Tong Zhang | 동일 | [PDF](https://tongzhang-ml.org/lt-book/lt-book.pdf) |
| 4 | The Principles of Deep Learning Theory | Roberts, Yaida, Hanin | Theoretical Principles of DL | [arXiv 2106.10165](https://arxiv.org/abs/2106.10165) |
| 5 | Machine Learning with Neural Networks | Bernhard Mehlig | Neural Networks and Learning Machines | [arXiv 1901.05639](https://arxiv.org/abs/1901.05639) |
| 6 | Deep Learning on Graphs | Yao Ma, Jiliang Tang | Graph Deep Learning | [PDF](https://yaoma24.github.io/dlg_book/dlg_book.pdf) |
| 7 | Algorithmic Aspects of Machine Learning | Ankur Moitra | ML: A Probabilistic Perspective | [PDF](https://people.csail.mit.edu/moitra/docs/bookexv2.pdf) |

| 10 | Advanced Data Analysis from an Elementary Point of View | Cosma Shalizi | Advanced Data Analysis | [PDF](https://stat.cmu.edu/~cshalizi/ADAfaEPoV/ADAfaEPoV.pdf) |
